Linux Internals & The Shell Workshop

DevOps begins at the operating system level. Linux is the backbone of the cloud, and a scholar must understand its Kernel-space vs. User-space architecture.

A. Permissions & The Chmod Strategy

Linux security is built on a Discretionary Access Control (DAC) model. Permissions are represented by a 3-digit octal code (User, Group, Others) or a symbolic representation.

# Example: Setting secure script permissions
chmod 755 deploy.sh # rwx for owner, r-x for others
ls -l # Result: -rwxr-xr-x

B. Process Management & Signals

Distributed systems communicate with processes via Signals. A scholar must understand how to manage the process lifecycle.

  • SIGTERM (15): Graceful shutdown request. The app can cleanup resources.
  • SIGKILL (9): Immediate termination. No cleanup allowed.

Docker: OS-Level Virtualization & Container Theory

Docker is the premier implementation of OS-level Virtualization, allowing isolated user-space instances (containers) to share the host OS kernel.

The Union File System (CoW):

Docker images use a Union File System (e.g., OverlayFS) to stack immutable Layers. Modifications follow Copy-on-Write (CoW) logic.

# Example: Multi-stage build for minimized footprint
FROM node:18-alpine AS builder
WORKDIR /app
COPY . .
RUN npm run build

FROM nginx:alpine
COPY --from=builder /app/dist /usr/share/nginx/html

Kubernetes (K8s): Distributed Orchestration

Kubernetes reconciles the Actual State of a cluster with the Desired State (Etcd) through continuous Control Loops.

A. The Control Plane

  • Kube-APIServer: The primary interface for the cluster.
  • Etcd: Consistent and highly-available key value store for cluster data.
  • Kube-Scheduler: Assigns work to nodes.
