Network Foundations: The Anatomy of a Request

Before a browser can render pixels, it must negotiate a complex handshake over the physical wire. Scholarly frontend engineering begins with understanding Latency and the TCP/IP Stack.

A. The DNS Resolution Phase

The browser first checks its local cache for an IP address. If missing, it queries a Recursive DNS Resolver. This process involves the Root, TLD (.com), and Authoritative Name Servers. Every millisecond here contributes to the TTFB (Time to First Byte).

B. The TCP 3-Way Handshake

TCP (Transmission Control Protocol) ensures data integrity. The handshake consists of three steps:

  1. SYN: Client sends a synchronization packet.
  2. SYN-ACK: Server acknowledges and sends its own sync packet.
  3. ACK: Client acknowledges. The connection is now open.

Browser Architecture & The Critical Rendering Path

Modern browsers are complex operating systems. Mastering the Critical Rendering Path (CRP) is the "holy grail" of frontend performance engineering.

A. Steps of the CRP

  1. DOM Construction: Tokenizing HTML into nodes.
  2. CSSOM Construction: Parsing CSS into a rule tree.
  3. Render Tree: Combining DOM and CSSOM.
  4. Layout: Calculating geometry.
  5. Paint: Converting boxes to pixels.

  • Web.dev: CRP
