Introduction to Databases & Persistence Theory

A database is an organized collection of structured information. In scholarly terms, it solves the Persistence Problem: reliably storing data beyond an application's lifecycle.

1. Database Management Systems (DBMS)

A DBMS is software for interacting with users and applications to capture and analyze data.

  • Relational (RDBMS): Structured tables (e.g., PostgreSQL, MySQL).
  • Non-Relational (NoSQL): Flexible document/graph formats (e.g., MongoDB, Redis).
📚 **Official Documentation:**
  • PostgreSQL Official Docs

Schema Design & Table Creation

A Schema is the blueprint defining data structure. We use CREATE TABLE to define columns and Data Types.

-- Example: Creating a Table
CREATE TABLE users (
    id SERIAL PRIMARY KEY,
    username VARCHAR(50) UNIQUE NOT NULL,
    email VARCHAR(255) UNIQUE NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

Basic CRUD Operations: INSERT, SELECT, UPDATE, DELETE

CRUD represents the four basic persistent storage operations, mapping directly to SQL commands.

SQL: Relational Algebra & Data Definition

SQL is the declarative implementation of Relational Algebra. Queries are operations on mathematical sets.

Advanced SQL: Analytic Functions & Complex State

Enterprise reporting uses Window Functions and Common Table Expressions (CTEs) for complex data analysis.

The ACID model ensures consistency through Atomicity, Consistency, Isolation, and Durability.
